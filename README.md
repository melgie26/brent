# Brent Nunweiler — Digital Contact Card

A mobile-first contact website for Brent Nunweiler. Visitors can save Brent's professional contact information or enter their own details and open a prefilled text message addressed to Brent.

No form data is stored or transmitted by the website. The visitor reviews the prepared message and taps **Send** in their phone's messaging app.

## Publish with GitHub Pages

1. Create a new GitHub repository and upload the contents of this folder.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **GitHub Actions**.
4. Push to the `main` branch. The included workflow publishes the `docs` folder.

The site is completely static and has no credentials, database, email service, or Google Sheet connection.
